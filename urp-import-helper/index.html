Features

Built to make converting imports a habit you don't have to remember

Safe conversion

Converts standalone .mat assets from Built-in Standard (metallic workflow) to URP/Lit, only when they pass the safety checks. Everything else is left unchanged and explained.

Three modes

Ask, Convert automatically, or Report Only (Change Nothing). Saved per user, per project.

Reporting

The Console report covers counts, warnings and next steps. Expand Details and click a row to ping that material in the Project window.

Manual conversion

Select .mat files or folders and convert on demand, in every mode, without importing another package.

Undo

Each converted batch is one named Unity Edit > Undo step, such as Convert 6 materials to URP. Reverted files are saved for you.

Optional CLI & MCP

On Unity 6+, analyze and convert through the Unity CLI or an MCP-capable AI agent. Not required for normal Editor use. Quick Start

01

Import detection

When Unity finishes importing a package, URP Import Helper checks the materials that came with it.

02

Review before converting

In Ask mode, a review window shows what will convert and what gets a warning. Choose Convert or Not now.

03

Convert and review results

Supported materials become URP/Lit. The Console report lists what changed.

04

Undo with confidence

Each batch is one named Edit > Undo step. Undo and Redo save the affected materials for you.

Compatibility & limitations

  • Needs a Unity project with URP installed and active. Editor-only.
  • V1 converts supported Built-in Standard (metallic workflow) materials to URP/Lit.
  • Custom and unsupported shaders are left unchanged. Embedded model materials and material variants aren't converted in V1.
  • Undo history doesn't survive an Editor restart. Use version control.
