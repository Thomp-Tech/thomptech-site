Getting Started — URP Import Helper

By Thomp Tech

URP Import Helper detects materials from imported Unity asset packages so you never forget to convert them.

URPIH safely converts supported Built-in Standard materials to URP/Lit, and explains what still needs attention.

Installing the tool does not automatically scan or convert your existing project.

URP Import Helper is Editor-only. It does not add runtime components to your game.

1. Requirements

  • A Unity project with the Universal Render Pipeline (URP) installed and active.

2. Installation

  1. Open your URP project in Unity.
  2. In Window > Package Manager > My Assets, locate URP Import Helper and import it into your project.
    • If you have a .unitypackage file, use Assets > Import Package > Custom Package instead.
  3. Allow Unity to finish importing and compiling.
  4. Find the tool under Tools > ThompTech > URP Import Helper.

Try the included demo

  1. Open Assets/ThompTech/URPImportHelper/Demo/URPIH_Demo.unity.
  2. The demo sphere initially appears pink because it uses the Built-in Standard shader.
  3. Right-click Demo_Standard.mat and select URP Import Helper > Convert Supported Materials to URP.
  4. The sphere should turn blue, using URP/Lit.
  5. Use Edit > Undo Convert 1 material to URP to restore the original material.

3. Your first package import

The default mode is Ask. Import an older Asset Store .unitypackage as usual. After Unity finishes importing and compiling, URP Import Helper checks the materials included in that import.

If supported materials are found, a non-modal review window appears:

  1. Review the number of materials ready to convert.
  2. Expand Details to inspect warnings and materials that will remain unchanged.
  3. Choose Convert to convert supported materials or Not now to leave them unchanged.

Important: The checkbox to automatically convert supported materials on future imports is checked by default. Uncheck it before clicking Convert if you want to stay in Ask mode. It takes effect only when you convert.

Closing the window keeps the review pending. Reopen it using Tools > ThompTech > URP Import Helper > Review Pending Import. Pending reviews do not survive a full Unity restart; use manual conversion afterward.

Not every import opens a window. If Unity's converter can handle materials but none are ready for URPIH, you may see a handoff window. Otherwise, check the Console for the import summary. The tool never blocks Unity with a modal import dialog.

4. Choose your import mode

Open Tools > ThompTech > URP Import Helper > When Importing:

  • Ask: Review supported materials before converting.
  • Convert automatically: Convert materials that pass the safety checks after each qualifying package import.
  • Report Only (Change Nothing): Analyze and report without converting any materials.

Your choice is saved per user, per project, and survives Editor restarts. Automatic detection applies to active .unitypackage imports, not ordinary asset edits or copied files.

5. Convert existing materials

You can convert materials on demand without importing another package:

  1. Select .mat files or folders in Unity's Project window.
  2. Right-click and choose URP Import Helper > Convert Supported Materials to URP. The same command is under Tools > ThompTech > URP Import Helper.

This works in every import mode, including Report Only. It converts only materials that pass the safety checks and saves successful conversions to disk immediately. Start with the folder you intend to convert rather than the entire Assets directory.

6. Understand results and Undo

The Console contains the conversion report: counts, warnings and next steps. Clean successful conversions may show a brief Scene view message without opening a new window. A receipt appears when failures or actionable leftovers need attention. Expand Details to inspect materials; clicking a material row pings it in the Project window without changing your selection.

Undo and Redo

A converted batch is recorded as one named Unity Edit > Undo step, such as Convert 6 materials to URP. Check the Edit menu for the correct step if other Editor actions happened afterward.

Undo restores the materials and URP Import Helper automatically saves those reverted files. Redo saves reapplied changes as well. Undo history does not survive a full Editor restart. Use version control or backups for long-term recovery.

7. Materials that need attention

V1 converts standalone .mat assets using Built-in Standard (metallic workflow) → URP/Lit. Supported textures and settings transfer with adjustments where the two shaders handle properties differently.

Other materials are left unchanged and explained:

  • Supported by Unity's converter: Follow the handoff to Window > Rendering > Render Pipeline Converter when this Unity/URP version's catalog is verified.
  • Unsafe Standard materials or missing shaders: Read the reported reason, including missing, mismatched or unreadable texture references. Check and restore dependencies before trying again.
  • Publisher or custom shaders: Check rendering and whether the publisher offers a compatible URP version. URPIH does not modify these shaders.
  • Appears intended for HDRP: Confirm whether the assets belong in your URP project. This is a hint, not a confirmed diagnosis.
  • TextMesh Pro: Its materials generally work in URP when the appropriate resources are installed.
  • Other shaders / already URP: Check appearance before deciding whether anything needs to change.

Known visual differences can include Transparent/Fade shadow behavior, detail maps that use UV1, or a custom render queue changing. A warning does not necessarily mean a conversion failed. Embedded model materials and material variants are not converted in V1.

Unity's converter handoff

If URPIH can convert some materials and Unity's converter can handle other materials, convert ours first, then open Unity's converter for the leftovers. If URPIH has nothing ready, use the direct handoff instead of running a pointless conversion first. Unity's Render Pipeline Converter may scan the whole project, not just the newly imported package.

8. Troubleshooting

No menu after installation? Wait for Unity to compile. Check the Console for errors. The tool is an Editor extension, not a GameObject component.

No review window after importing? Confirm you're in Ask mode and check the Console. Not every package contains convertible materials; a handoff window may appear instead.

Some materials are still pink? Read the reported shader and reason. Some need Unity's converter, publisher-provided shaders or missing dependencies; V1 doesn't convert every shader.

URP isn't active? Configure the active URP pipeline before converting. URP Import Helper does not migrate an entire project's rendering pipeline.

Lost a pending review after restarting Unity? Select the imported folder and use the manual conversion command.

NOT RESTORED after a failure? Follow the red report's Undo before saving instruction in the current Editor session. Don't assume the material was restored.

An imported asset's demo has Input errors? The asset pack may use the legacy Input Manager. If appropriate for your project, check Project Settings > Player > Active Input Handling; Both can resolve that separate pack issue. It isn't caused by material conversion.

9. Optional CLI and AI agent integration

On Unity 6+, a supported Unity Pipeline installation can register two optional commands:

  • urpih_analyze_materials — read-only analysis.
  • urpih_convert_materials — conversion that requires explicit confirm true.

The current adapter is pinned to com.unity.pipeline 0.8.0-exp.1. Neither the Pipeline package nor the Unity CLI is required for normal Editor use. For setup, examples, result interpretation and unattended-run recovery, see CLI & MCP Quick Start.

Headless command runs have no Unity Undo; use version control to restore changed materials. CLI conversion in an open Editor retains the normal live-Editor Undo behavior.
