Featured Project: URP Import Helper

A Unity tool to make importing into URP easier

URP Import Helper is an upcoming Unity asset built to help with importing into URP (Universal Render Pipeline).

  • Never forget to switch: catches standard (Built-in) materials on import so they get converted to URP.
  • Your choice of mode: Ask (prompts with a pop-up), Automatic (converts on import), or Report Only (simulates the conversion without changing anything).
  • Clear reports: shows which materials won't convert and where they're located.
  • Agent-ready: works with AI agents in Unity via MCP or the command line (CLI).

Releasing soon. Stay tuned for the launch.
